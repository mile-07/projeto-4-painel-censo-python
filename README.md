# projeto-4-painel-censo-python
Painel interativo em Python (pandas e Streamlit) com dados do Censo Escolar 2024 (INEP): escolas de 30 municípios de SP em quatro regiões. Filtros por região, localização e porte; indicadores, gráficos de características e infraestrutura, mapa e lista de escolas. Projeto 4 de Análise de Dados para Pesquisas em Políticas Públicas (FGV).
